# Sistema de Prestação de Contas CG — v39

## Ajustes

- A mesma conta bancária pode ser cadastrada mais de uma vez quando o tipo for diferente.
- Exemplo permitido:
  - Banco do Brasil, agência 1369-2, conta 34.377-3 — Conta corrente;
  - Banco do Brasil, agência 1369-2, conta 34.377-3 — Aplicação.
- Continua bloqueado o cadastro repetido quando banco, agência, conta e tipo forem iguais.
- Retirado o selo “MODO LEVE” do cabeçalho.
- As paginações e otimizações internas foram preservadas.
