TRANCELIM v142 — PASSO A PASSO

1. No Supabase, abra SQL Editor.
2. Clique em New query ou use a aba que já está aberta.
3. Apague o texto antigo da consulta.
4. Abra o arquivo SCRIPT_SUPABASE_TRANCELIM_v142.sql.
5. Copie todo o conteúdo e cole no SQL Editor.
6. Clique em Run.
7. Ao terminar, confira o resultado da consulta final.
8. Publique no GitHub os arquivos do ZIP UPLOAD_GITHUB_TRANCELIM_v142.zip.
9. Use Ctrl + F5 no navegador após a publicação.
