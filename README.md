# TRANCELIM v206

Pacote integrado para publicação no GitHub Pages.

## Módulos
- Gestão Patrimonial v134
- Encerramento Mensal v47
- Prestação de Contas CG preservada

## Ajustes desta versão
- Corrigido o erro que impedia o salvamento em lote no Patrimônio.
- A janela central conta cada item confirmado no banco e exibe a quantidade final salva.
- Ao concluir, oferece os botões `Concluir` e `Voltar ao cadastro`.
- No cadastro, o CNPJ aparece antes do fornecedor e consulta fornecedores já usados em outros bens.
- Ao selecionar um CNPJ conhecido, o nome do fornecedor é preenchido automaticamente.
- Estrutura do pacote mantida limpa, sem acumular históricos antigos.

## Publicação
Envie o conteúdo deste pacote para a raiz do repositório do GitHub Pages, mantendo as pastas e o arquivo `.nojekyll`.
