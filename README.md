# TRANCELIM v208

Pacote integrado para publicação no GitHub Pages.

## Módulos
- Gestão Patrimonial v135
- Encerramento Mensal v48
- Prestação de Contas CG preservada

## Ajustes desta versão
- Pendências Patrimoniais não retorna mais ao portal durante a rolagem.
- Cadastro de Bens voltou a permitir selecionar itens e excluir os selecionados em uma única confirmação.
- Incluída a coluna Data de cadastro.
- Incluídos filtro por data e ordenação por itens mais recentes, mais antigos e número patrimonial.
- A listagem inicia pelos cadastros mais recentes para facilitar a conferência dos últimos lotes.
- Mantida a paginação de 25, 50 ou 100 itens e o total geral cadastrado.

## Publicação
Envie o conteúdo deste pacote para a raiz do repositório do GitHub Pages, mantendo as pastas e o arquivo `.nojekyll`.
