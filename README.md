# TRANCELIM v205

Pacote integrado para publicação no GitHub Pages.

## Módulos
- Gestão Patrimonial v133
- Encerramento Mensal v47
- Prestação de Contas CG preservada

## Ajustes desta versão
- FERDT: Anexo III zerado usa o modelo oficial sem redesenhar valores; apenas referência e data final da competência são atualizadas.
- Patrimônio: janela central acompanha o salvamento item a item, mostra a quantidade concluída e libera botão OK ao final.
- Estrutura do pacote limpa: arquivos antigos de atualização foram retirados e scripts/instruções ficaram em `documentacao/`.

## Publicação
Envie o conteúdo deste pacote para a raiz do repositório do GitHub Pages, mantendo as pastas e o arquivo `.nojekyll`.
