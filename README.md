# TRANCELIM v209

Pacote integrado para publicação no GitHub Pages.

## Módulos
- Gestão Patrimonial v136
- Encerramento Mensal v48
- Prestação de Contas CG preservada

## Ajustes desta versão
- Os bens consolidados como “Sem item de despesa” no relatório Depreciação por Grupo passam a aparecer em Pendências Patrimoniais.
- Pendências também identificam ausência de nota fiscal, CNPJ, ordem de compra/fornecimento e valor de aquisição.
- Incluído filtro por tipo de pendência.
- Incluído resumo clicável com as principais pendências e respectivas quantidades.
- A origem da lista segue a mesma competência e a mesma base do relatório de Depreciação por Grupo.
- Mantidos seleção/exclusão em lote, data de cadastro e ordenação dos bens.

## Publicação
Envie o conteúdo deste pacote para a raiz do repositório do GitHub Pages, mantendo as pastas e o arquivo `.nojekyll`.
